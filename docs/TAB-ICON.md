# Transparentes Browser-Icon

Das Tab-Zeichen zeigt ein großes oranges Y aus der YUNG-Wortmarke auf transparentem Hintergrund. Das kleine Querformat-Logo mit dunkel gefüllten Randpixeln wurde für den Browser-Tab ersetzt. Das Icon wird als PNG und als ICO mit 16, 32, 48 und 64 Pixeln exportiert; alle vier Ecken wurden auf Alpha 0 geprüft.

Dateien:

- `N:/YUNG Event OS/public/brand/yung-tab-v2.png` – neue, versionierte Browser-Adresse
- `N:/YUNG Event OS/src/app/icon.png` – Next.js-Icon
- `N:/YUNG Event OS/src/app/favicon.ico` – Fallback mit mehreren Auflösungen

Erstellt mit dem eingebauten Imagegen-Tool, anschließend technisch als PNG/ICO exportiert. Das große App-Logo wurde nicht verändert. Die neue PNG-Adresse ist als öffentliches Branding-Asset freigegeben; geschützte App-Daten bleiben geschützt.

## Verwendeter Prompt

Create a favicon asset extracted from this existing YUNG brand logo. Use only the leftmost letter Y from the supplied logo, preserving its exact distinctive geometry: two broad angled arms, vertical thick stem with the diagonally cut lower edge. Do not include U, N, G or the ornament above U. A single flat solid orange #fa754d letter Y, centered large in a square image with about 8% transparent breathing room on each side. Actual RGBA transparency everywhere outside the Y, including all four corners and between the arms. Absolutely no black/dark/white square, no badge, no border, no shadow, no gradients, no additional text. Crisp clean antialiased silhouette, optimized for legibility at 16 and 32 pixels. This is a faithful extraction of the existing Y symbol, not a logo redesign.
